# ChatGPT kurulumu

> **Erişim notu:** ChatGPT Skills, belirli plan/çalışma alanlarında kullanılabilir. Menüler hesapta görünmüyorsa Skills yetkisi mevcut olmayabilir. Resmî kaynak: https://help.openai.com/en/articles/20001066-skills-in-chatgpt

## Kurulum — ZIP yükleme

1. Depoyu ZIP olarak indirin veya içinde SKILL.md, references/, scripts/, examples/ bulunan **tek kök klasörlü skill ZIP** hazırlayın.
2. ChatGPT kenar çubuğundan **Plugins → Skills** bölümünü açın.
3. **Create → Upload from your computer** seçeneği varsa ZIP dosyasını seçin.
4. Taramayı ve varsa gerekli incelemeyi tamamlayın. Yüklenen skill listede göründüğünde kullanmaya başlayın.
5. Test edin: “AETHER ile ekteki ürün fotoğrafı için iki premium reklam konsepti değerlendir.”

## Skills hesabınızda yoksa

- ZIP dosyasını bir ChatGPT sohbetine veya Work projesine kaynak olarak ekleyebilirsiniz; bu kalıcı veya otomatik etkinleşen skill kurulumu değildir.
- Prompt'ta “SKILL.md içindeki AETHER talimatlarını bu iş için uygula” diyerek geçici yönerge olarak kullanabilirsiniz.
- Gerçek görsel üretimi için ayrı bir görsel üretme özelliğinin etkin olması gerekir; Python kompozit işlevleri de çalışma ortamına bağlıdır.

## Güvenli kullanım

Ürün referansı ve fiyat gibi kesin verileri kullanıcıdan alın. Dosyadaki script'leri çalıştırmadan önce inceleyin.
