# Iteration through ChatGPT Image

Inspect the actual image and diagnose in order:
1. Wrong product/model, identity drift, invented claim or wrong copy.
2. Selected-concept drift: missing defining features, changed core metaphor or composition; compare against `concept-fidelity.md`. Also check footer filled, banned text decorations, clipped content and weak hierarchy.
3. Perspective, scale, contact, lighting or reflection errors.
4. Off-brand palette, generic concept, excessive decoration.
5. Fine visual polish and legibility.

Use the previous output as a reference for a targeted ChatGPT Image edit. Include original product references when identity matters. State what to change and what to retain. Fix one or two priority issues at a time, then inspect the whole result because edits may change untouched areas.

“Too crowded”: remove secondary copy or decorative objects; do not merely shrink all content or consume the footer. “More creative”: strengthen the concept, framing, lighting or scale relationship; retain the footer and no-line rule. “Fix the headline”: provide the exact required replacement and request no other changes.

Retain image-only production throughout. Do not repair text, masks, shadows, dimensions or crops with code or outside editors. If corrections cannot meet a strict requirement, disclose the specific remaining limitation.

After a revision, repeat the concept-fidelity gate as well as general QA. Preserve the original selected-concept brief unless the user explicitly changes direction. Never raise a score or rewrite the intended concept merely to make the latest image pass.
