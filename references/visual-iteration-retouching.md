# Module 06 — Visual Iteration & Retouching

**Activate for:** revisions, weak renders, messy masking, spacing changes, type edits and image retouching.

## Diagnose before changing

Inspect full-resolution and realistic mobile thumbnail output. Categorize:

1. **Factual fatal:** changed product, distorted logo, invented claim/price, wrong dimensions or spelling.
2. **Composition:** poor hierarchy, cramped negative space, cropping or safe-zone collisions.
3. **Photographic:** mismatched perspective, floating product, impossible shadows, matte halo.
4. **Art direction:** generic concept, off-brand colors or decorative overload.
5. **Polish:** jagged edge, fringing, low fidelity, inconsistent sharpness or contrast.

Fix in priority order. Don't regenerate the source-locked product to correct a background problem. Rebuild only the scene plate and reapply the source layer; fix copy using a separate text overlay.

## Iteration protocol

Save before image and a concise correction note. Pick explicitly between: adjust layout, replace plate, repair mask, replace shadow, re-typeset, or regenerate concept. Only regenerate the concept if its central idea fails. Limit each pass to one or two main problems, compare to reference and brief, then inspect again.

## Export review

Open actual final pixels, compare source product at 100%, verify visible copy, check 3:4 and 4:5 grid crops. Use AETHER audit/export for mechanical checks. These scripts cannot independently judge premium aesthetics. Report unverified checks honestly.
