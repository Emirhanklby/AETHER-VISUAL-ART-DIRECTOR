# Module 05 — Brand Visual DNA

**Activate for:** repeat work for the same brand, coherent ad series, multi-product promotions, campaign variations, user-supplied brand guides.

## Brand design context (reusable record)

Record brand context in working notes **only when the user provides / approves brand assets and details**. Useful schema:

```yaml
brand_name: "Example brand"
audience: "Who must notice the campaign"
positioning: "How the brand should feel"
colors:
  primary: ["#000000"]
  accent: ["#FF0000"]
  neutral: ["#F5F2EA"]
fonts:
  headline: "approved typeface as a visual target"
  body: "approved typeface as a visual target"
product_identity_rules: "reference details to retain in ChatGPT Image"
photography: "camera signature, contrast, light, materials"
composition: "flexible hierarchy; empty bottom 12%; no decorative lines around text"
avoid: ["generic template gloss", "invented product details"]
copy_voice: "short, unambiguous, proof-based"
```

Unknown brand values stay unknown; never infer precise codes, brand fonts, special discounts, store hours or legal claims from aesthetics.

## Campaign consistency vs repetition

Keep shared brand values (type family, core palette, level of restraint, product fidelity and editorial discipline) while allowing new concepts, camera moves and scale. Do not make every post the same template with a new SKU. For a set, maintain 1–2 recognizable visual motifs and vary hierarchy only as needed by each product/offer.

## Quality check

Compare new visual against the approved brand guide and previous approved outputs. If no approved guide/assets exist, label all suggested visual DNA as **proposed** until approved. A user's example image may represent style inspiration, not permission to recreate protected art.

Use ChatGPT Image for the complete output. Treat precise font and color matching as targets, not verified native typography or measured color compliance. Repeated motifs must never violate the empty footer or no-line rules.
