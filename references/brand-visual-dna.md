# Module 05 — Brand Visual DNA

**Activate for:** consistent campaign families, repeated brand work, product ranges, and user-approved brand guides.

## Brand design context

Create a reusable project context only from user-provided or approved facts; unknown values must stay unknown.

~~~yaml
brand_name: "Example"
audience: "Who should notice this visual"
positioning: "Intended brand feeling"
colors:
  primary: ["#000000"]
  accent: ["#FF0000"]
  neutral: ["#F5F2EA"]
fonts:
  headline: "approved font + available file"
  body: "approved font + available file"
product_identity_rules: "preserve source artwork, geometry and logos"
photography: "camera signature, contrast, light, materials"
composition: "strong hierarchy, generous space, adaptable grid"
avoid: ["generic template gloss", "invented specs"]
copy_voice: "short, factual, direct"
~~~

Never infer exact corporate colors, approved font names, offer prices, store hours, claims or discounts merely from aesthetic references.

## Consistency without repetition

Keep shared typography, core palette, restraint, product fidelity, and recognizable motifs. Change viewpoint, composition and concept appropriately. Avoid stamping every new SKU into the same poster template.

## Check

Compare to actual brand guide and approved examples. If unapproved, label proposed visual DNA as a suggestion. References are inspiration, not a license to reproduce protected artwork.
