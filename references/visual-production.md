# ChatGPT Image production

Use only ChatGPT Image for the entire design and its revisions. Follow the active tool's instructions for references, image return, and transparency. Do not fabricate tool arguments.

1. Inspect supplied product/style references. Include the correct actual images in the tool call; a URL or description alone is not proof the generator received the reference.
2. Build one complete advertisement brief: product and scene, art direction, exact copy, palette, camera, lighting, hierarchy, footer reserve and no decorative text lines.
3. Generate the whole final visual, including text, in ChatGPT Image. Do not split production into background generation followed by external product/text assembly.
4. Inspect the returned result where accessible. Use available metadata for real dimensions/encoding. Prompted dimensions are intent, not verified output.
5. Correct through a targeted ChatGPT Image edit; compare again with original references and exact copy.
6. Return the image using the supported display mechanism. Request PNG if supported and desired; never mislabel another encoding. Never promise exact-size downloads when the tool cannot supply them.

Do not use external compositing, coded artwork, local image-processing libraries, external typography overlays or mechanical export fixes. Do not assume editable layers or native font files. If generation is unavailable, explain that and offer a prompt. If strict source-pixel identity is requested, explain that this generative workflow cannot guarantee it; preserve appearance as closely as possible without claiming an exact match.
